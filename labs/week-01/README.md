## Knowledge Assessment Answers

### 1. Importance of professional development platforms used by IT professionals.
Professional development platforms like LinkedIn and GitHub are crucial for IT professionals because they serve as a live, digital portfolio. Instead of just listing skills on a traditional paper resume, these platforms allow an individual to showcase their actual codebase, configuration files, and active technical learning to global employers and future clients.

### 2. Software tools commonly used in System Administration.
* **Virtualization (Hypervisors):** VirtualBox, VMware Workstation Player (used to run and test isolated server environments safely).
* **Code Editors:** Visual Studio Code (used to write, edit, and manage automation scripts and system configurations).
* **Version Control:** Git and GitHub Desktop (used to track file modifications and maintain backups).
* **Terminal & CLI:** Windows Terminal, Git Bash (used to run local and remote server management commands).

### 3. Describe the role of Git and GitHub in version control and portfolio development.
* **Version Control:** Git tracks every change made to configuration scripts. If an error occurs, the administrator can easily roll back to a stable, working state to avoid system downtime.
* **Portfolio Development:** GitHub acts as a public cloud repository where students and professionals can publish their scripts, guides, and documentation to build an industry-ready technical portfolio.
